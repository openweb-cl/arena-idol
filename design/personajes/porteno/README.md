# El Porteño — dorsal pendiente

Ficha propuesta; gameplay sin implementar ni aprobar. La dirección es **futbolista caricaturesco en combate arcade**.
No hay diseño final aprobado. No cambiar cara, proporciones o equipación entre
imágenes sin registrar una propuesta y la decisión del propietario.

## Punto de partida

[Lámina elegida por el propietario](../../referencias/propietario_2026-10-31/01-plantel-caricaturesco.jpg): **fila 2, columna 4**. Es la referencia principal de carácter,
proporción y energía. Sus números, clubes y mecánicas deportivas no se incorporan.
Dorsal vigente: **dorsal pendiente**.

Futbolista caricaturesco de la tarjeta histórica verde: camiseta verde con puños blancos propios, short, medias, botines; gorro náutico pequeño y cuerda de muñeca como accesorios. Sin abrigo/coraza.

Cara humana ficticia ancha y barbuda, amable pero firme, según lenguaje del bosquejo marítimo.

Paleta propuesta: base `#21844e`, secondary `#f5f3e9`, light `#71ddda`, signal `#71ddda`.
La paleta es guía; no sustituye materiales actuales sin revisión.

| Etapa | Evidencia / estado |
|---|---|
| V0 — pruebas geométricas | No entregada para este personaje; no inventar una versión anterior. |
| V1 — GLB provisional | Sin modelo 3D entregado. |

| V3 — modelo refinado | Pendiente de V2; Blender, GLB, rig y clips en Godot. |
| Candidato final | Pendiente de prueba visual, animación, legibilidad y rendimiento. |

El nombre V1 agrupa el estado del pipeline; las versiones locales de cada GLB
siguen en su documento de arte (p. ej., Turbo V1.1). No implica que todos estén
igual de avanzados. Las exploraciones recientes **no** cuentan como V2 aprobado.
