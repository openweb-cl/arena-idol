# El Zorro del Desierto — dorsal pendiente

Ficha propuesta; gameplay sin implementar ni aprobar. La dirección es **futbolista caricaturesco en combate arcade**.
No hay diseño final aprobado. No cambiar cara, proporciones o equipación entre
imágenes sin registrar una propuesta y la decisión del propietario.

## Punto de partida

[Lámina elegida por el propietario](../../referencias/propietario_2026-10-31/01-plantel-caricaturesco.jpg): **fila 3, columna 2**. Es la referencia principal de carácter,
proporción y energía. Sus números, clubes y mecánicas deportivas no se incorporan.
Dorsal vigente: **dorsal pendiente**.

Futbolista caricaturesco humano ligero: camiseta naranja/arena con zonas oscuras propias, short y medias, botines ágiles; pelo en puntas sugiere el zorro sin disfraz animal.

Cara humana ficticia pícaro-amable; sin hocico, máscara de animal, cola, orejas de peluche o armadura.

Paleta propuesta: base `#db8d35`, secondary `#303037`, light `#efca7e`, signal `#ffcf5b`.
La paleta es guía; no sustituye materiales actuales sin revisión.

igual de avanzados. Las exploraciones recientes **no** cuentan como V2 aprobado.
