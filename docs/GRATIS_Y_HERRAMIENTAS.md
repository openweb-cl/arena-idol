# Empezar gratis: herramientas y límites

| Necesidad | Opción inicial | ¿Gratis? / advertencia |
|---|---|---|
| Motor | Godot 4 estable (validación 4.6.3), https://godotengine.org | Código abierto, gratis |
| Código y tareas | GitHub Free, https://github.com | Plan gratuito con límites |
| IDE | VS Code o editor Godot | Gratis |
| Pixel/sprites | Krita, LibreSprite | Gratis / revisar licencias |
| Animación | Godot AnimationPlayer, Krita | Gratis |
| Audio | Audacity | Gratis |
| Arte prototipo | Kenney, https://kenney.nl/assets | Página indica CC0; verificar paquete individual |
| Arte adicional | OpenGameArt, https://opengameart.org | Licencias distintas: revisar cada asset |
| Demo web estática | GitHub Pages / itch.io | Puede servir para client web, NO servidor de juego |
| Base de datos | ninguna en vertical slice; luego evaluar Supabase | Free tiene límites y condiciones cambiantes |
| Servidor partidas | localhost / PC propia durante pruebas controladas | Hosting de producción NO garantizado gratis |
| Android | Export local APK sideload para test | Distribución tiendas tiene requisitos/costos |

**Presupuesto etapa M0-M2:** USD 0 de licencias obligatorias si usan sus propios PCs y herramientas gratuitas; sí hay costos de tiempo, equipos, energía, conectividad y potencialmente arte. Multijugador, publicación, dominio, soporte y licencias comerciales pueden costar.

**Límite de propiedad intelectual:** no copiar Brawl Stars, su HUD, personajes, texturas, mapas, audio, marca ni logos; tomar solo patrones generales del género y construir visual/lógica propios.
