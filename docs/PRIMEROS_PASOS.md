# Primeros pasos vigentes — combate 3D

El proyecto ya contiene una demo técnica ejecutable en `game/`. Sigue el README
de raíz para importar Godot 4.6.3 estándar y ejecutar F5. No reinicialices Git ni
crees otro repositorio. Usa ramas independientes; main solo por PR aprobado.

Lee DECISIONES_Y_ALCANCE, GDD, MECANICAS y ARQUITECTURA. Batalla de Ídolos es la
prioridad, sin balón obligatorio. El tutorial anterior 2D/porterías queda sustituido.
Codex y Claude deben tomar tareas según COORDINACION_AGENTES y CONTRATO_ARTE_3D.
No instalar backend ni servicios de pago. Recursos provisionales no son arte final.
