# Proyecto Godot 4 — combate 3D

Importar `project.godot` en Godot 4.6.3 estándar y pulsar F5. Mobile por defecto;
Compatibility disponible desde el editor o `--rendering-method gl_compatibility`.

Menú → selección Turbo #11 / Rey #23 → Batalla local contra bot → resultado /
revancha. Modelos y efectos son **provisionales de mecánicas**, no arte final.

Controles, pruebas, parámetros del inspector y límites: [README de raíz](../README.md).
La raíz exportable es esta carpeta. No añadir referencias privadas de `data/` o
mockups de `design/` del repositorio. Android/táctil y red todavía no validados.
